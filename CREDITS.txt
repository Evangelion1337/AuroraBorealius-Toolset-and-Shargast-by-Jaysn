COMPILATION FIXES & MODULE REPAIR
----------------------------------
All compilation issues in HOPE_Shargast_CH1.mod and
HOPE_Shargast_CH2.mod were diagnosed and fixed programmatically by
an AI agent (opencode/big-pickle) operating through the Aurora Borealis
toolset.

Specific fixes applied:
  1. Timeout resolution: Removed merge conflict markers (<<<<<<<, =======)
     from 5 module scripts that caused nwnsc to hang indefinitely
  2. Self-include removal: Filtered #include "se_respawn_inc" from
     se_respawn_inc.nss to break infinite include recursion
  3. Skip list management: 13 problematic module/include files redirected
     to use clean copies from user include directory
  4. Missing constant injection: Added SAVING_THROW_TYPE_PARALYSE,
     GetLastOpener() declaration, and other missing declarations
  5. Function signature repair: Fixed GenerateBossTreasure calls missing
     the required OBJECT_SELF second argument in prc_inc_leadersh
  6. Missing include injection: Added #include "x2_inc_switches" to
     sd_ai_inc_spawn.nss for CREATURE_VAR_USE_SPAWN_STEALTH
  7. Include substitution: Forced nw_o2_coninclude to use full
     user_include_dir version (containing ShoutDisturbed and
     GenerateNPCTreasure bodies) instead of module ERF stub
  8. Default argument resolution: Added definition for GenerateNPCTreasure
     and other missing functions
  9. Compiler flags: Added -n (install dir) and -w (suppress benign warnings)
     to nwnsc invocation
  10. ERF save fix: Changed save format from V1.1 (32-byte resrefs) to V1.0
      (16-byte resrefs) to match nwn-lib-rs serialization output, fixing
      "Failed to demand Module info resource" error in NWN:EE nwserver
