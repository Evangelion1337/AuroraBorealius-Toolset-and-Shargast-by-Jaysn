# Aurora Borealis Toolset + HOPE_Shargast

Shargast Persistent World (PRC8) — compiled modules for NWN:EE, built using the Aurora Borealis toolset.

## Contents

- **toolset/** — Aurora Borealis toolset source (rust-neveredit workspace)
- **module/** — HOPE_Shargast CH1 and CH2 module source (NSS scripts) and NWN include files
- **releases/** — Pre-compiled NCS zip and full module source zip
- **CREDITS.txt** — Full attribution, license info, and build notes

> **Note:** Compiled `.mod` files are too large for git. Download them from the [Releases](../../releases) page.
